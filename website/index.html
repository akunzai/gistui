>_ gistui

Your GitHub Gists, next to the files in your working directory. Diff the two and push or pull with one key. Runs on the GitHub CLI, so it stores no token of its own.

bash
$ curl -fsSL https://raw.githubusercontent.com/akunzai/gistui/main/install.sh | bash
  detects your platform, verifies the SHA-256, installs to ~/.local/bin

$ cd ~/dotfiles && gistui

Linux, macOS, and Windows. Homebrew, Scoop, PowerShell, crates.io, mise, and building from source · Source on GitHub · Latest release

Why

Against gh gist

The official CLI is non-interactive and text-only. gistui shows both lists at once and ranks your gists against the file you are on, so finding the right one is not a copy-paste of an id.

Against the web UI

The browser cannot see the file you are editing. gistui launches in a directory and works against what is actually on disk there.

Against your own mistakes

No existing file — local or remote — is overwritten without its diff and a y/n first. Destructive remote actions confirm one at a time.

The keys

Move

Tab 1 2
switch panes — local files on the left, gists on the right
j k
move the selection; h l scroll a row too long to fit
a
flip the anchor — which pane's selection the other one ranks against
/
filter the focused pane by path, filename, description, or id

Compare

Enter
diff the local file against the gist, with word-level inline changes
Space
preview the gist file, syntax-highlighted
H
revision history — browse, diff, and restore an older version

Write

u d
upload the local file, or download the gist file
n
create a gist from the selected local file, secret or public
p P
pin the pair, then open Pins to see and sync every pinned mapping
S
sync a pinned pair — whichever side is newer wins

Manage

g
gist manager: description, visibility, star, fork, compact, delete
C
settings — theme, mouse, scan depth, diff context
?
the full keymap for whichever screen you are on

Also: ; or right-click for a menu of what is valid right now, Ctrl+p for the command palette. The mouse works by default.

Requirements

  • The GitHub CLI. Install gh and run gh auth login once. gistui shells out to it at runtime and keeps no credentials of its own.
  • A terminal. Any modern one with a monospace font. Every mark gistui draws is single-width, so columns stay aligned.
  • A clipboard tool, if you want y to copy. pbcopy, clip, wl-copy, xclip, or xsel. Without one, copy reports that instead of failing.
